# Telegram Queue Bot v2.8

Бот ведёт очереди на сдачу работ в темах Telegram-группы. Администратор открывает запись, участники выбирают желаемый номер или случайное место, а бот проводит жеребьёвку по окончании регистрации. После пары итоговая очередь остаётся в группе.

## Стек

| Компонент | Назначение |
|---|---|
| Python 3.12 и `asyncio` | Запуск бота и фоновая обработка сроков в `queuebot/runner.py` |
| aiogram 3.31+ и Telegram Bot API | Long polling, команды, сообщения и кнопки в `handlers.py` и `presentation.py` |
| SQLite в режиме WAL | Очереди, участники, обмены и история. Хранилище и миграции в `db.py`, правила очереди в `service.py` |
| Google OR-Tools CP-SAT | Жеребьёвка в `optimizer.py` с учётом пожеланий и истории. Общая удовлетворённость сохраняется на уровне не менее 95% рассчитанного максимума |
| python-dotenv, `zoneinfo` и tzdata | Настройки из `.env` и часовые пояса, включая Windows |
| pytest, Docker и Docker Compose | Локальные тесты и запуск на сервере. Контейнер использует Python 3.12 |

## Локальный запуск на Windows

1. Установите 64-битный Python 3.12. Получите токен у [@BotFather](https://t.me/BotFather).
2. Откройте PowerShell в папке `telegram_queue_bot`, где лежат `requirements.txt` и `.env.example`.

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

   Замените `PUT_YOUR_TOKEN_HERE` своим токеном. Оставьте `DATABASE_PATH=./data/queuebot.sqlite3`, чтобы SQLite использовала папку проекта. Храните токен в `.env`.

3. Установите зависимости и запустите бот.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m queuebot.runner
   ```

   В журнале появится `Running @имя_бота`. Для остановки нажмите Ctrl+C.

### Проверка в Telegram

Добавьте бота администратором в тестовую группу и дайте ему право удалять сообщения. Для очередей по предметам включите темы в группе. В нужной теме отправьте `/queue Программирование 25.12.2026 13:45 6ч`, подставив будущую дату. Откройте запись по кнопке из группового сообщения, затем проверьте `/close_reg ID` или `/cancel ID`. ID указан в объявлении как `№N`.

### Настройки

| Переменная | Что задаёт |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота |
| `TIMEZONE` | Часовой пояс ввода и отображения времени. По умолчанию `Europe/Moscow` |
| `DATABASE_PATH` | Путь к SQLite. Для приведённого развёртывания используйте `./data/queuebot.sqlite3` |
| `MAX_PARTICIPANTS` | Лимит участников на очередь. По умолчанию `35` |

Права на групповые команды берутся из настроек Telegram-группы. Пара длится 100 минут.

Имена участников по Telegram `@username` можно задать в локальном файле `queuebot/roster.csv` с заголовком `username,first_name,last_name`. Без файла бот использует имена из Telegram. Для переноса списка скопируйте его на сервер отдельно по SSH. После изменения списка перезапустите локального бота или пересоберите контейнер на сервере.

## Развёртывание на Ubuntu

1. На сервере установите Docker Engine с плагином Docker Compose. Проверьте установку командой `sudo docker compose version`. [Инструкция Docker для Ubuntu](https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository)
2. У себя в PowerShell, из папки проекта, соберите архив исходников и отправьте его по SSH. Замените `user@server.example.com` своим логином и адресом сервера.

   ```powershell
   tar --exclude=__pycache__ --exclude=roster.csv -czf queuebot-src.tar.gz queuebot tests requirements.txt Dockerfile docker-compose.yml .env.example README.md .gitignore
   ssh user@server.example.com "mkdir -p telegram_queue_bot"
   scp queuebot-src.tar.gz user@server.example.com:telegram_queue_bot/
   ssh user@server.example.com
   ```

3. В открытой SSH-сессии распакуйте проект и настройте `.env`.

   ```bash
   cd ~/telegram_queue_bot
   tar -xzf queuebot-src.tar.gz
   cp .env.example .env
   chmod 600 .env
   nano .env
   ```

   Вставьте токен и сохраните файл. Для переноса имеющихся очередей сначала остановите локального бота, затем отдельно скопируйте всю папку `data/` на сервер. Пример из PowerShell для стандартного расположения базы:

   ```powershell
   scp -r data user@server.example.com:telegram_queue_bot/
   ```

4. Остановите локальный экземпляр с этим токеном, если он ещё работает. Запустите бот на сервере.

   ```bash
   sudo docker compose up -d --build
   sudo docker compose ps
   sudo docker compose logs -f --tail=100
   ```

   Выйти из просмотра логов можно через Ctrl+C. Бот продолжит работу в фоне. Compose хранит базу в папке `./data` на сервере и перезапускает контейнер после сбоя. Long polling требует исходящего HTTPS к Telegram. Открывать входящий порт для бота не требуется.

### Обновление существующей установки

Из папки проекта на сервере остановите контейнер и сохраните копию конфигурации и всей папки с SQLite.

```bash
sudo docker compose stop
(umask 077 && sudo tar -czf - .env data > "../queuebot-backup-$(date +%F-%H%M%S).tar.gz")
```

Загрузите новый архив исходников в ту же папку, распакуйте его и снова выполните `sudo docker compose up -d --build`. Бот применит миграции при запуске. Если в старой базе были очереди на одну пару под разными названиями темы, они сохранятся со своими ID и названиями. При объединении статистики тема получает последний сохранённый баланс для каждого участника. Если база обновляется с версии до v2.8, при первом запуске сработает предусмотренный в v2.8 одноразовый сброс старой статистики жеребьёвки.

## Команды

| Команда | Действие |
|---|---|
| `/queue название дата время срок_записи` | Создать очередь в текущей теме |
| `/close_reg ID` | Закрыть запись досрочно и провести жеребьёвку |
| `/finish_lesson ID` | Завершить очередь после начала пары |
| `/cancel ID` | Отменить очередь. После отмены можно создать новую на ту же пару |
| `/my` в личке | Обновить карточки очередей, в которых вы сейчас состоите |
| `/info`, `/help` в личке | Открыть справку |

Пример команды — `/queue Высшая математика 25.12.2026 13:45 6ч`. Укажите будущую дату, время начала пары и длительность записи от 3 минут до 7 дней. Срок задаётся, например, как `30м` или `6ч`. При неверных параметрах бот удаляет сообщение с командой без ответа.

Переименование Telegram-темы сохраняет её историю жеребьёвок. После жеребьёвки участники могут предложить обмен местами или выйти. Предложение обмена действует пять минут. Вышедший участник может вернуться в конец очереди до начала пары.

Очередь завершается автоматически через 100 минут после начала пары. Бот обновляет объявление в группе и удаляет личные карточки завершённых и отменённых очередей. Если карточка старше 48 часов, бот пытается убрать её кнопки редактированием. При временном сбое Telegram фоновой обработчик повторяет обновление объявления и очистку карточек. [Ограничения Telegram на удаление сообщений](https://core.telegram.org/bots/api#deletemessage)

## Тесты

В PowerShell после установки зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты используют временную SQLite и имитируют ответы Telegram. Для проверки живого бота пройдите сценарий из раздела «Проверка в Telegram» со своим токеном.
