# Telegram Queue Bot

Telegram-бот для организации очередей на сдачу лабораторных, практических и других учебных работ. Администратор открывает запись в группе или в теме, участники записываются по кнопке, а бот публикует порядок сдачи в том же сообщении.

## Как работает очередь

1. Администратор указывает время начала занятия, длительность записи и режим жеребьёвки.
2. Участники записываются через личный чат с ботом. В режиме с пожеланиями каждый может указать желаемый номер или выбрать случайное место.
3. Бот проводит жеребьёвку по окончании записи или по команде администратора. Участники могут обменяться местами по взаимному согласию. До начала занятия вышедший участник может вернуться в конец очереди.
4. Через 100 минут после начала занятия бот завершает очередь. Итоговый порядок остаётся в группе, а личные карточки закрываются.

## Команды

Групповые команды доступны администраторам Telegram-группы.

| Команда | Действие |
| --- | --- |
| `/queue [предмет] дата время срок_записи [режим]` | Открыть запись в текущей теме или группе |
| `/close_reg ID` | Досрочно закрыть запись и провести жеребьёвку |
| `/finish_lesson ID` | Завершить очередь после начала занятия |
| `/cancel ID` | Отменить очередь |

```text
/queue Высшая математика 25.12.2026 13:45 6ч
/queue 25.12.2026 13:45 30м 0
```

Подставьте будущую дату. Время начала указывается в часовом поясе бота, длительность записи — от 3 минут до 7 дней. Если предмет опущен, бот берёт известное название темы или название чата. Названия тем сохраняются из событий их создания и переименования. Для темы, название которой бот ещё не получил, используется название чата. [Telegram Bot API](https://core.telegram.org/bots/api#forumtopiccreated)

В личном чате `/my` открывает карточки действующих очередей, а `/info` и `/help` показывают справку.

## Режимы жеребьёвки

| Режим | Как распределяются места |
| --- | --- |
| `1` или без параметра | Бот учитывает пожелания и историю жеребьёвок по предмету. Суммарная удовлетворённость пожеланий составляет не менее 95% от оптимума |
| `0` | Бот случайно перемешивает всех записавшихся участников. В личной карточке нет выбора номера, а результат не влияет на историю жеребьёвок |

## Стек

| Технология | Роль |
| --- | --- |
| Python 3.12, `asyncio` | Обработка событий и фоновые задачи |
| aiogram 3, Telegram Bot API | Long polling, команды и интерактивные карточки |
| SQLite, WAL | Хранение очередей, участников, обменов и истории |
| Google OR-Tools, CP-SAT | Распределение мест в режиме с пожеланиями |
| python-dotenv, `zoneinfo`, tzdata | Конфигурация и часовые пояса |
| pytest | Проверка правил очереди, миграций и сценариев Telegram с имитацией API |
| Docker, Docker Compose | Контейнеризация |

## Архитектура

- Обработка команд и формирование сообщений и кнопок. [`handlers.py`](queuebot/handlers.py), [`presentation.py`](queuebot/presentation.py)
- Правила очереди и расчёт порядка сдачи. [`service.py`](queuebot/service.py), [`optimizer.py`](queuebot/optimizer.py)
- Схема данных, миграции и транзакции. [`db.py`](queuebot/db.py)
- Отслеживание сроков и повторное обновление сообщений при временных сбоях. [`runner.py`](queuebot/runner.py)
